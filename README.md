# Compass New Tab

<div align="center">

**重新定义你的新标签页** · 对标 Infinity 体验、从零独立开发的开源新标签页扩展

原生 HTML / CSS / JavaScript · Chrome Manifest V3 · 无框架 · 无构建 · 无网络请求 · 数据全本地

</div>

Compass New Tab 是一个从零开发的 Chrome 新标签页浏览器扩展。它提供漂亮的本地壁纸、四引擎五类别搜索、可收纳的图标文件夹、多分页网格与完整的个性化设置，让每次打开新标签页都高效且赏心悦目。

---

## ✨ 功能特性

- **网格卡片 + 多分页**：底部圆点切换分页，每页独立网格与排序
- **添加站点**：16 个分类的本地预设站点库 / 自定义图标（纯色·预设·本地上传）/ 添加当前页面
- **图标文件夹**：浮窗网格、编辑模式红叉移出、右侧滑出编辑面板、拖拽排序、站点多归属
- **右键菜单**：站点卡（编辑 / 复制网址 / 移动至 / 新建文件夹 / 添加到分页 / 删除）、文件夹卡（打开全部 / 重命名 / 删除）
- **本地壁纸库 + 风车随机**：收藏池优先、约 300ms 淡变过渡、1h / 12h / 24h / 每次开新标签页四档轮换
- **侧边栏四 Tab**：主页 / 添加 / 我的 / 设置，标准 / 极简两种设置模式
- **我的页**：头像昵称、`.infinity` 备份导出导入、修复数据
- **待办小组件**：右下角卡片，输入实时自动保存到 IndexedDB
- **智能搜索**：百度 / 谷歌 / 必应 / Yahoo × 网页 / 图片 / 资讯 / 视频 / 地图

## 🚀 快速开始

### 方式一：下载即用（推荐）

1. 下载最新打包：**[compass-new-tab-extension-v1.0.0.zip](https://aka.doubaocdn.com/s/AHbhETf9Nb)**（含全部图标，解压即可加载）
2. 解压到任意目录（如 `E:\compass-new-tab`）
3. 打开 Chrome 地址栏输入 `chrome://extensions/`
4. 打开右上角 **开发者模式**
5. 点击 **加载已解压的扩展程序**，选择解压后的目录（能直接看到 `manifest.json` 的那一级）
6. 打开一个新标签页即可使用

### 方式二：从源码加载

```bash
git clone https://github.com/compassscout/compass-new-tab.git
```
然后重复上面的第 3–6 步，选择克隆目录即可。

## 🔒 隐私与安全

- **无任何网络请求**：所有站点、文件夹、分页、壁纸、待办数据保存在本地（IndexedDB），外观配置在 localStorage
- **最小权限**：仅申请 `storage` 与 `activeTab`，不请求书签 / 历史 / 通知等敏感权限
- 站点网址仅允许 http/https，用户输入经转义渲染，不执行外部脚本
