TAB STUDIO 网页版（v2.2.1）
==========================

这是「网页版」：一份纯静态站点，不装扩展、不用 Electron，用浏览器打开就能用。

怎么打开
--------
不要直接双击 newtab.html（浏览器会拦住 ES Module，页面是空白的）。任选一种：

1) 本机起一个静态服务（最简单，Windows 自带 Python 时可用）
   在本文件夹空白处按住 Shift + 右键 → 「在此处打开 PowerShell 窗口」，执行：
       python -m http.server 8080
   然后浏览器访问 http://localhost:8080/newtab.html

2) 有 Node.js 的话：
       npx serve .

3) 也可以把这几个文件原样上传到任意静态空间（GitHub Pages / Cloudflare Pages / 自己的服务器），
   访问 …/newtab.html 即可。

在线版（免下载）
----------------
https://tab-studio.pages.dev/newtab.html

版本区别
--------
- 网页版：浏览器里用，数据存在该浏览器的 IndexedDB，和扩展版互不相通
- 扩展版：装进 Chrome/Edge，成为新标签页，能读浏览器历史/书签（可选授权）
- 桌面版：独立窗口的 exe，源码可改、Ctrl+R 生效

网页版不支持的部分
------------------
浏览器历史记录、书签（属于浏览器本体数据，网页拿不到，面板里会给出说明）；
其余站点、文件夹、分页、壁纸、待办、笔记、天气都可用。
