FEATURES

让新标签页真正属于你

对标 Infinity 的完整体验，从零独立实现，无框架、无构建、无网络请求。

轻松管理常用网站

16 个分类的本地预设站点库、自定义添加当前页面；图标支持纯色、预设与本地图片上传，颜色、大小、圆角、布局 2×4 到 3×3 自由定制。

图标文件夹

把站点分组收纳进文件夹，一键打开全部；浮窗网格、编辑模式红叉移出、右侧滑出编辑面板、拖拽排序，站点可同时归属多个文件夹。

四引擎五类别搜索

百度 / 谷歌 / 必应 / Yahoo × 网页 / 图片 / 资讯 / 视频 / 地图，回车即在新标签页打开结果。搜索框大小、圆角、类别、按钮均可自定义。

本地壁纸与风车

内置本地壁纸库与风车随机按钮，收藏池优先、约 300ms 淡变过渡，支持 1 小时 / 12 小时 / 24 小时 / 每次开新标签页四档自动轮换，离线可用。

多分页网格

底部圆点切换分页，每页拥有独立的网格与排序；分页可自由增删，站点单份原件、分页与文件夹仅作引用视图。

我的 · 备份与待办

头像昵称、`.infinity` 一键导出导入与数据修复；右下角待办卡片，输入实时自动保存到 IndexedDB，换机前导出备份即可无缝迁移。

完整设置面板，标准与极简双模式

壁纸遮罩与模糊、打开方式、通知、视图缩放、布局、图标、搜索框、字体、动画，全部分组真实生效；「还原设置」只重置外观，绝不触碰你的站点与数据。

GET STARTED

三步装好，马上使用

Chrome / Edge 等 Chromium 浏览器均可，30 秒即可完成。

1

下载并解压

点击右上角 下载即用 获取 compass-new-tab-extension-v1.0.0.zip，解压到任意目录。

2

打开开发者模式

地址栏输入 chrome://extensions，打开右上角「开发者模式」开关。

3

加载已解压的扩展

点击「加载已解压的扩展程序」，选择解压目录（能直接看到 manifest.json 的那一级）。

隐私与安全，从设计上保证

Compass New Tab 没有服务器、没有账号、没有追踪。你的数据只属于你的浏览器。

零网络请求

站点、文件夹、分页、壁纸、待办全部保存在本地 IndexedDB，外观配置在 localStorage，离线可用。

最小权限

仅申请 storage 与 activeTab，不请求书签、历史、通知等任何敏感权限。

可迁移

通过「我的 → 导出备份数据」生成 `.infinity` 文件，换浏览器、重装系统都能一键恢复。
